# Agenda de Contatos

Aplicação em Python, feita em dupla, para cadastrar, listar, buscar e remover contatos via terminal.

## Funcionalidades

- Cadastrar um novo contato (nome, telefone e email)
- Listar todos os contatos cadastrados
- Buscar um contato pelo nome
- Remover um contato

## Como executar

```bash
python agenda.py

### 8. Perguntas de Reflexão

**1. Qual é a diferença entre uma Issue e uma Pull Request? Em que momento do trabalho cada uma entra?**
Uma Issue serve para registrar e organizar uma tarefa ou problema. A Pull Request é usada depois que a alteração foi feita, para pedir revisão e aprovação antes de colocar o código na `main`.

**2. Por que é importante que a outra pessoa da dupla revise o código antes do merge, mesmo em um projeto pequeno como este?**
Porque outra pessoa pode encontrar erros ou sugerir melhorias que passaram despercebidos por quem escreveu o código.

**3. O que aconteceria se a dupla nunca usasse branches, e sempre commitasse direto em `main`?**
As alterações poderiam se misturar e causar conflitos ou erros no código principal, além de não haver uma etapa adequada de revisão.

**4. Para que serve o GitHub Actions? Por que ele roda em um servidor do GitHub, e não no computador de vocês?**
O GitHub Actions automatiza tarefas, como verificar se o código está funcionando corretamente. Ele roda nos servidores do GitHub para que as verificações sejam feitas automaticamente, independentemente do computador de cada integrante.

**5. Qual a diferença entre o README e a Wiki? Em que situação vocês usariam cada um?**
O README apresenta as informações principais do projeto, como instalação, uso e funcionalidades. A Wiki é mais adequada para documentação detalhada, tutoriais e informações maiores sobre o projeto.

**6. O quadro do Project ajudou a organizar o trabalho da dupla? O que vocês fariam diferente em um projeto maior?**
Sim, ajudou a dividir as tarefas e acompanhar o que precisava ser feito. Em um projeto maior, usaríamos mais etapas, responsáveis, prazos e uma organização mais detalhada das tarefas.
